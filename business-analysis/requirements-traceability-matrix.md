# Requirements Traceability Matrix (RTM)

## 1. Project Information

- **Project:** Nova Bank — Mobile Banking Application Enhancement
- **Role:** Business Analyst
- **Document Type:** Requirements Traceability Matrix
- **Status:** Portfolio Case Study

## 2. Purpose

The RTM links business requirements to user stories and proposed UAT test cases to ensure requirements are covered during testing.

## 5. Notes

- Test case IDs refer to the proposed UAT test cases planned for this portfolio project.
- Test execution and results will be recorded separately.
- The matrix should be updated if requirements or user stories change.
