# User Acceptance Testing (UAT) Test Cases

## 1. Project Information

- **Project:** Nova Bank — Mobile Banking Application Enhancement
- **Role:** Business Analyst
- **Document Type:** UAT Test Cases
- **Status:** Proposed — Not Executed

## 2. Purpose

These test cases verify whether the proposed mobile banking features meet the documented business requirements.

## 3. UAT Test Cases

| Test Case ID | Requirement ID | Test Scenario | Expected Result |
|---|---|---|---|
| TC-01 | BR-01 | Register using valid details | Registration completes successfully after required verification. |
| TC-02 | BR-02 | Log in using valid and invalid credentials | Valid credentials allow access; invalid credentials display an error. |
| TC-03 | BR-03 | View account balance | The correct account balance is displayed. |
| TC-04 | BR-04 | Open transaction history | Recent transactions and their details are displayed. |
| TC-05 | BR-05 | Add a beneficiary with valid details | The beneficiary is added after required validation and verification. |
| TC-06 | BR-06 | Submit a valid fund transfer | The transaction is processed and its status is displayed. |
| TC-07 | BR-07 | Submit a valid bill payment | The payment is processed and its status is displayed. |
| TC-08 | BR-08 | Complete a transaction that triggers a notification | The relevant notification is initiated and reflects the confirmed transaction status. |
| TC-09 | BR-09 | Check successful, failed, and pending transactions | Each transaction displays the correct status. |
| TC-10 | BR-10 | Open self-service support | Help topics and relevant guidance are displayed. |
